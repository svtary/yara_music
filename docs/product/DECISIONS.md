# Yara — Frozen Decisions

## Navigation

Mobile: Home / Explore / Yara / Community / Me  
PC: Home / Explore Music / Talk to Yara / Community / Me

## Module boundaries

- Home = proactive, personal, today-oriented
- Explore = browsing and discovery
- Yara = intent, reasoning, planning, decisions, tasks
- Community = music-centered social sharing and shared experiences
- Me = identity, journey, collection, settings

## Important boundary decisions

- Home ≠ Explore
- Explore ≠ Yara
- Journey ≠ Collection
- Saved Results ≠ Me Collection
- Memory Management ≠ Journey
- Public Profile ≠ Me
- Community must not degrade into a generic feed product
- Yara must not degrade into an agent launcher or prompt shortcut list
- Home must not become a content dumping ground
- Explore must not become a category directory only
- Me must not become a settings / asset dumping ground
- Search is global and also appears as natural-language input in Yara
- Suggested Tasks are modules / entry patterns, not separate agent tabs
- Structured AI Results must not all be chat bubbles

## Community

Feed / Activities / People. Intent: **Music Taste → People → Shared Experience**.

### Architecture Amendment — Messaging

- Messaging is a secondary Community utility, not a sixth primary navigation item or a Community discovery tab.
- C-08 Messages Inbox is the aggregate carrier for All / People / Groups conversation-list states.
- C-09 Conversation is one human-conversation carrier with Direct / Group variants.
- Human messaging remains visually and semantically distinct from Yara AI Conversation.
- Music objects shared in chat reuse canonical Explore detail pages.
- Activity Conversation / Participant Messaging is deferred as a future capability.

## Me

Identity / Journey / Collection / Settings.

## Signature interaction

**Contextual Ask Yara / Ask Yara about THIS**.
Session context and long-term memory must be visibly distinguishable.

## Technical scope

Do not design technical architecture yet.
Music Graph / Knowledge Graph is a future AI infrastructure dependency for later AI Architecture / Technical Design.
