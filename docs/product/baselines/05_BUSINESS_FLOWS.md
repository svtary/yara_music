# Yara — Business Flow Summary

Conceptual business-operation context only; this is not technical architecture.

Recommendation: context → taste interpretation → candidates → ranking → explainable result → feedback → future preference update.

Music Understanding: object/question → intent → trusted retrieval → source-aware synthesis → explanation → related music/follow-up.

Mood: mood/check-in + time/weather/recent listening/taste → recommendation → playback → feedback.

Concert: concert intent → clarify constraints → event/ticket/travel/stay/route info → compare → structured plan → save/external destinations.

Vinyl/CD: release/pressing → identification → edition analysis → price/condition comparison → recommendation → external purchase.

Playlist: requirement → constraints → retrieval → sequence generation → edit/optimization → save/play.

Social Matching: taste signals + shared music/concert/collection + social intent → meaningful similarity/complementarity → recommendation → profile/activity.

Music Journey: user-confirmed event/moment → memory extraction → timeline placement → editable reflection → future recall/personalization.

Companion Loop: interaction → contextual task → user action → feedback → optional memory confirmation → personalization improvement.

Future AI infrastructure dependency: Music Graph / Knowledge Graph. Do not design it yet.
