**Ask Yara about THIS**

## Context Bar states

Default / Focused / Typing / Context Attached / Generating / Result Available / Follow-up / Error / Disabled.

## Context Object

Supports Single / Multiple / Remove / Replace / Add Context. Session context must not silently become long-term memory.

## Dynamic Quick Ask

Context-specific suggested actions; never the same prompts everywhere.

## Progressive disclosure

Level 1 Ambient → Level 2 Assist → Level 3 Conversation / Task.

## Result routing

Simple factual/interpretive → Inline Result.
Single-object exploratory → Assist panel/sheet.
Multi-turn/ambiguous → Conversation.
Multi-step planning/comparison/decision → Full Task / Structured Result.

## Structured result types

Music Recommendation / Music Explanation / Playlist / Concert Plan / Vinyl Comparison / Taste Match / Journey Reflection.

## Memory signature

Lightweight, transparent, controllable: Indicator / Why This? / Confirmation / Edit / Forget.

## Figma signature components

Context Bar / Context Object / Quick Ask / Suggested Question / Inline Insight / AI Input / Conversation Message / Tool Progress / Task Progress / Citation / Memory Indicator / Structured Result / Follow-up Actions.
