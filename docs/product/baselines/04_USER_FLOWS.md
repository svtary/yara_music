# Yara — Core User Flows

## 1 Discover Music

Home / Explore / Search → Track / Album / Artist → related music → play → save → optionally Ask Yara.

## 2 Understand Music

Object Detail → Story / Lyrics / History / Reviews / Influence → Ask Yara → Inline Insight or Conversation → related music → save / continue.

## 3 Mood Music Recommendation

Home Daily Brief / optional check-in → contextual recommendations → playback → feedback → future personalization. If no check-in, automatic context still supports recommendations.

## 4 Concert Planning

Explore Experience → Concert Detail → Plan with Yara → Conversation / Clarification → Task Progress → Structured Concert Plan → Save Plan → external ticket / travel / hotel destinations.

## 5 Vinyl / CD Discovery

Explore Records → Record Detail → Ask Yara → edition / pressing comparison → structured decision result → save → external purchase.

## 6 Playlist Creation

Yara Home → describe requirement → Conversation / Clarification → Playlist Result → edit / accept → save → play / share.

## 7 Music Social

Community → Taste Match / People Discovery → Public Profile → Follow → shared music / activity → Activity Detail.

### Messaging Amendment

- Direct: Community → People → Public Profile → Follow / Message → C-09 Direct Conversation → Share Music → canonical music detail → continue conversation.
- Group: Community → Groups → Group Detail → Join → Joined → Enter Group Chat → C-09 Group Conversation → Share Music → continue conversation.
- Return: Community → C-08 Messages Inbox → existing Direct / Group conversation → continue conversation.
- Activity Conversation / Participant Messaging is deferred.

## 8 Music Journey

Me → Journey → Music Moment → view / edit → Ask Yara about this moment / period → reflection.

## 9 AI Companion Loop

Interaction → contextual understanding → useful result → feedback / user-approved memory → better future personalization → repeat.
