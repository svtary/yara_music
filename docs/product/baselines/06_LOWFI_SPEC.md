# Yara — Low-fi Wireframe Baseline Summary

Global mobile reference: 393×852, 4-column grid, 16px margin, 12px gutter, 8pt spacing system, Auto Layout, Mini Player / Bottom Navigation where applicable.

## Home

Header → Daily Brief → Continue → Ask Yara → Insights → Mini Player → Bottom Navigation.

## Explore

Object-first, not a uniform card grid. Core families: Explore Home / Search / Track / Album / Artist / Playlist / Story / Concert / Festival / Venue / Record.

## Yara

Y-01: Natural-language input P0; Suggested Tasks secondary.
Y-02: fixed header + visible context + scroll stream + fixed composer.
Y-03: task summary + missing info + continue.
Y-04: user-understandable task status; no private chain-of-thought.
Y-05: shared structured-result shell with task-specific blocks.
Y-06: Saved Music / Saved Plans tabs.
Y-07: compact history list.

## Community

Feed primary; Activities / People as discovery entries. Feed cards require Music Object Context. Taste Match must be explainable. Public Profile is public-only. Group Detail stays restrained.
